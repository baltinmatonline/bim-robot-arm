# The Donut Robot

An interactive simulator of a two-joint planar robot arm and its
**configuration space**.

Drag the target and the arm follows; drag the rock and the forbidden region
recomputes. The right-hand panel is the map of every pose the arm can hold —
a square whose edges wrap around, which makes it the surface of a **torus**
(a donut). The red region is every pose in which the arm would hit the rock.

Built for the Night of Science by Mathematics-Driven Research Seminar, Baltic Institute of Mathematics.

*Single self-contained HTML file — no dependencies, no build step, works offline
once loaded.*
